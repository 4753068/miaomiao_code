🐱 喵喵 (MiaoMiao) - 端对端加密通讯应用

普通 App：聊天记录 = 公开日记
喵喵 App：聊天记录 = 焚毁的密函

喵喵是一款将隐私安全置于首位的端对端加密聊天应用。无论是挚友闲聊还是亲密沟通，我们确保每一条信息仅对您和接收方可见。在喵喵，安全不是选项，而是默认设置。

✨ 核心安全特性

🔒 真正的端对端加密 (E2EE)
采用高强度加密协议，消息仅在发送端与接收端解密。传输全程密文流转，除必要的离线消息暂存外，服务器不保留任何聊天记录。所有图片、音视频文件均通过 AES 算法加密存储，离开用户设备即无法破解或打开。

🛡️ 本地访问控制
强化终端安全边界。应用启动及查看历史记录均需通过密码或生物识别（指纹/面容）验证，从物理层面杜绝设备借用或丢失导致的隐私泄露。

🔥 多维数据销毁体系
为应对各类隐私风险场景，我们构建了全方位的数据防护机制：
阅后即焚：支持阅读后自动销毁 & 发送后定时自毁
验证失败自毁：连续输错密码自动清空本地记录
伪装密码 (Duress Password)：输入特定假密码触发数据销毁，从容应对强制检查
远程擦除：支持远程指令一键删除设备数据
无感清除：后台静默删除，不留操作痕迹
定时清理：自定义周期自动净化本地缓存

👁️ 防窥录入模式
内置输入隐私保护。编辑消息时自动模糊/隐藏聊天上下文，有效防止旁人通过屏幕预览偷窥敏感内容。

🖼️ 媒体内容防窥
拒绝意外曝光。收到的图片与视频默认以隐藏状态展示，需手动点击确认后方可查看，彻底避免公共场合下的尴尬瞬间。

🏗️ 支持自建服务器
不信任第三方？我们提供完整的服务端源码与部署教程。您可以搭建专属私有服务器，所有数据（照片、影音、消息中转）完全由您掌控，实现真正意义上的数据主权。

🎭 应用伪装与隐蔽
支持自定义桌面图标与应用名称，可伪装为游戏、日历、新闻客户端等普通应用。让私密沟通完美融入日常界面，兼顾安全与隐蔽。
